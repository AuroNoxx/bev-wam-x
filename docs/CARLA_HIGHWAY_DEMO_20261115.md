# CARLA 高速短程演示实测

2026-11-15，运行 `logs/highway-demo/20261115-174833`。这是独立控制与模拟器演示，没有加载或修改 Flow 权重，没有启动训练或批量采集。

## 场景和控制

- CARLA 客户端/服务端均为 `1.0-a1770de89`，Town12，Tesla Model 3。
- Road 1157 / lane -3，检查 s=100..1800 m：三个同向驾驶车道，车道宽 3.5 m，无路口，直线与缓弯。OpenDRIVE 的通用 `town` 类型不能用来证明法定高速道路分类或限速。
- 单车、无其他交通参与者；阴天，无降水、路面湿度为零。
- Traffic Manager 使用地图特权信息，目标速度 100 km/h，关闭自动变道，固定种子 20261115。它不是本项目的 Flow / 世界模型闭环，也不是已验收的数据采集专家。
- 同步物理步长 0.05 s，加速与巡航 55 s，随后退出自动驾驶，用制动与几何车道跟踪完成停止。

## 复现与产物

先用项目内 CARLA 启动入口运行端口 2100 的服务并加载 Town12，再执行：

```powershell
.\.venv-carla-ue5\Scripts\python.exe scripts/run_highway_demo.py
```

脚本只接受最高 100 km/h、10–60 秒加速巡航时长；拒绝在有其他车辆的世界运行。每次建立独立输出目录，结束销毁自建车辆/传感器并恢复世界同步设置。Traffic Manager 8100 应专用于本次演示。

- `report.json`：结果与局限。
- `telemetry.jsonl`：每个物理帧的位置、速度、车道、控制量与阶段。
- `route.json`：预检查路段。
- `frames/*.png`：121张跟车相机原始画面，约2 Hz。
- `replay-4x.gif`：带模拟时间/速度的4倍速回放；回放速度与模拟速度不同。
- `source-sha256.json`：执行脚本指纹。
- `post-run-state.json`：自建车辆/传感器已清理，世界恢复异步。

训练环境、模型、数据 split 和旧评估结果均未修改。
