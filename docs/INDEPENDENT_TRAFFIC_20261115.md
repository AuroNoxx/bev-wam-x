# 独立背景交通高速重跑

2026-11-15：已在可见 CARLA 窗口完成一场九车、29 秒、约 988 米测试。八辆背景车由独立进程中的 CARLA Traffic Manager 自主驾驶；助手只根据当前观测控制自车。结果属于独立交通下的短程高速巡航调试，不是复杂博弈或专家认证。

## 独立性边界

- `scripts/independent_background_traffic.py` 使用随机种子抽取八辆车的位置与 100–130 km/h 目标速度。它只在初始化时设置这些参数，随后自主跟车、制动和选择是否变道；没有配合自车的动作时间表，没有运行中人为调整背景车。
- 自主变道开关启用，未使用强制变道。随机抽样交通分布是环境初始化，不承诺每辆车的实际速度一直处于此区间。
- 自车 autopilot 始终关闭，使用现有 Pure Pursuit + 速度 PI。助手作了 15 次速度/车道决策，均保持中间车道；未加载 Flow 或世界模型。
- 决策观测只包含当前自车与 180 米内车辆状态，不含背景车目标速度、路线、随机种子和未来动作。运行期间没有读取私有配置；结束后程序只输出重试种子是否相同的布尔校验，不输出具体种子或目标参数。
- 背景进程负责同步时钟，自车进程提交自车控制量并请求推进一帧。时钟请求不含自车计划，也不含背景车控制命令。
- 这是逻辑接口隔离，不是操作系统权限隔离；助手知道交通分布和程序实现。观察来自仿真真值，无遮挡模型，不等于真实传感器或 OCC 感知闭环。
- 仿真在助手思考时暂停，不能证明实时决策延迟达标。仅显示观测到的实际行为，不能推断未发生动作的应对能力。

各背景车在 580 个记录帧中分别有 566–579 帧实际输出超过 0.01 的油门或刹车，证据见 `telemetry.jsonl` 中 `background_applied_controls` 和 `independence-audit.json`。车辆不是仅依靠初始化速度滑行。

自车观测到中间车道畅通，随后发现远处前车约 121 km/h、间距超过 160 米，因此没有必要变道。过程中与左右邻车并行，并在保持车道时逐渐驶到部分邻车前方。这不是“跟车后主动变道超车再返回”的完整动作测试，也未验证右侧通过其他车辆的交通法规合规性。

**本次没有发生切入、急刹或变道，不能认定已验证其应对能力。** 开启自主变道不等于实测产生变道；本版本 TM 已有高速变道局限的历史诊断，本次不据开关状态宣称该问题解决。自车最高 127.91 而不是实际达到 130；最初约 1 秒低于 100，也如实保留。

同车道 TTC/时距采用 road-s 和车长代理，统计仅匹配相同 road 和中心车道；跨道路连接处车辆会从该项统计中排除。邻车道纵向重叠不等于碰撞。碰撞传感器覆盖全部九车，每仿真帧检查自车车身四角是否在指定驾驶车道联合区域；这些不构成连续扫掠安全证明。

## 保留的基础设施失败

1. `20261115-205119`：6 秒后发现背景车持续滑行。TM 所在进程未推进同步时钟，该次明确标为无效自主交通测试，见 `validity.json`。
2. `20261115-205505`：车辆生成/稳定阶段模拟器等待 60 秒超时，驾驶记录为 0 秒。
3. `20261115-205742`：修正同步归属后，0.25 秒发生 Windows 同步文件写入/替换权限冲突。
4. `20261115-205934`：0.20 秒读取同步文件时发生临时权限冲突。
5. `20261115-210105`：在读取端修正过程中结束的启动尝试，模拟器再次超时；未作为成功测试。
6. 重启期间另有未连接到服务的启动目录，原始文件保留，没有清理或掩盖。

同步原因经匹配版本源码核查：[`Simulator.cpp`](https://github.com/carla-simulator/carla/blob/a1770de89/LibCarla/source/carla/client/detail/Simulator.cpp) 在同步帧时推进当前进程注册的 TM，而 [`TrafficManagerRemote.cpp`](https://github.com/carla-simulator/carla/blob/a1770de89/LibCarla/source/carla/trafficmanager/TrafficManagerRemote.cpp) 的 `SynchronousTick()` 返回 false。因此改由拥有 TM 的背景进程推进世界。

同步消息改为逐帧不可变文件，读写均有有上限的临时文件锁重试。200 条并发消息小测试通过，随后完成 580 帧驾驶。自 `205742` 起所有重试复用相同未披露种子，结束后已验证一致；未按驾驶成绩挑选随机场景。默认配置现已移除重试引用，下一次新运行重新抽样。

## 文件与复用

- 入口：`scripts/agent_drive_bridge.py --scenario independent_highspeed_traffic`，仍需外部逐次提交自车决策，不是无人值守驾驶策略。
- `decisions.json`：每次观测、理由和自车命令；`telemetry.jsonl`：逐帧运动、保护与背景实际控制量。
- `scenario.json`、`bridge-source.py`、`helper-source.py`、`background-source.py`：运行时版本；额外哈希在 `independence-audit.json`。
- `assessment.json`：离线指标；`replay-4x.gif`：四倍速回放；`frames`：2 Hz 原始图像。
- 启动及驾驶过程中通过窗口截图确认 CARLA 可见。结束时按预定时长关闭记录，背景进程报告已退出；不声称车辆完成停车。最后收尾检查发现 CARLA 进程已不存在、RPC 不可连接，退出原因未核实，因此不声称窗口仍开着或已重新核实恢复后的世界设置。完整驾驶报告和回放已保存。

没有训练、删除旧模型或修改固定规划架构。下一步需独立背景策略自然产生更多交互的重复测试，并分别报告场景覆盖；本次日志先作为诊断数据，不直接认证成专家训练集。
