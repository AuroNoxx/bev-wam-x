\frac{R(\tau_i) - \mu_R}{\sigma_R + 10^{-6}}$，直接优化策略分布向高安全、高通行效率轨迹收敛。4. 核心损失函数与奖励函数数学定义4.1 第一阶段 SFT 联合损失函数 $\mathcal{L}_{\text{SFT}}$$$\mathcal{L}_{\text{SFT}} = \lambda_{\text{reason}} \mathcal{L}_{\text{reason}} + \lambda_{\text{fm}} \mathcal{L}_{\text{fm}} + \lambda_{\text{kin}} \mathcal{L}_{\text{kin\_smooth}} + \lambda_{\text{world}} \mathcal{L}_{\text{world}}$$因果意图推理损失 $\mathcal{L}_{\text{reason}}$（权重 $\lambda_{\text{reason}} = 0.5$）：$$\mathcal{L}_{\text{reason}} = \text{CrossEntropy}\big(\text{MLP}_{\text{intent}}(\text{<REASON\_TOKEN>}),\ y_{\text{intent}}\big)$$条件流匹配损失 $\mathcal{L}_{\text{fm}}$（权重 $\lambda_{\text{fm}} = 1.0$）：
对归一化控制序列 $u \in \mathbb{R}^{T \times 2}$（对应 $[a_x, a_y]$）及积分位置轨迹 $\tau(u) \in \mathbb{R}^{T \times 2}$，在流时间 $s \sim \mathcal{U}(0, 1)$ 下插值 $u_s = (1 - s) u_0 + s u_1$（$u_0 \sim \mathcal{N}(0, I)$）：$$\mathcal{L}_{\text{fm}} = \mathbb{E}_{s, u_0, u_1} \left[ \left\Vert{} v_\theta(u_s, s, H_{\text{cond}}) - (u_1 - u_0) \right\Vert{}_2^2 \right] + 0.2 \cdot \text{SmoothL1}\big(\tau(\hat{u}_1),\ \tau_{\text{gt}}\big)$$运动学平滑与舒适度损失 $\mathcal{L}_{\text{kin\_smooth}}$（权重 $\lambda_{\text{kin}} = 0.2$）：
直接惩罚离散加加速度（Jerk，一阶加速度差分除以 $\Delta t$）与高速侧向力超限：$$\mathcal{L}_{\text{kin\_smooth}} = \frac{1}{T-1} \sum_{t=1}^{T-1} \text{Huber}\left( \frac{a_{t+1} - a_t}{\Delta t} \right) + \frac{1}{T} \sum_{t=1}^{T} \text{ReLU}\big(\vert{}a_{y,t}\vert{} - 3.0\big)^2$$动作条件世界模型损失 $\mathcal{L}_{\text{world}}$（权重 $\lambda_{\text{world}} = 0.5$）：
同时监督未来 $\Delta t \in \{+1\text{s}, +2\text{s}, +3\text{s}\}$ 的残差潜特征与非对称高速走廊动态障碍物占用概率图 $P_{\text{occ}}$：$$\mathcal{L}_{\text{world}} = \sum_{\Delta t \in \{1, 2, 3\}} \left[ \text{FocalLoss}\big(P_{\text{occ}}^{(t+\Delta t)},\ Y_{\text{occ\_gt}}^{(t+\Delta t)}\big) + 0.1 \cdot \left\Vert{} \Delta Z_{t+\Delta t} - \text{sg}(Z_{t+\Delta t}^{\text{ema}} - Z_t) \right\Vert{}_2^2 \right]$$硬性验收门控：验证集上预测特征的 Latent MSE 与 Occupancy Brier Score 必须显著低于静态 Persistence 基线（直接复制当前帧 $Z_t$），才允许开启的世界模型对轨迹分支的反馈。4.2 第二阶段 GRPO 强化学习与闭环选优奖励函数 $R(\tau^{(k)})$对于第 $k$ 条候选轨迹 $\tau^{(k)} = \{(x_t^{(k)}, y_t^{(k)}, v_t^{(k)}, a_{x,t}^{(k)}, a_{y,t}^{(k)}, \kappa_t^{(k)})\}_{t=1}^T$，综合奖励定义为：$$R\big(\tau^{(k)}\big) = w_{\text{prog}} R_{\text{progress}} - w_{\text{col}} C_{\text{collision}} - w_{\text{ttc}} C_{\text{ttc}} - w_{\text{dyn}} C_{\text{dynamics}} - w_{\text{lane}} C_{\text{lane}}$$未来 OCC 碰撞穿透代价 $C_{\text{collision}}$（权重 $w_{\text{col}} = 10.0$）：
将候选轨迹在 $+1\text{s}, +2\text{s}, +3\text{s}$ 的车体包络采样点（前保、中心、后保及四角）通过双线性插值 F.grid_sample 投影至世界模型预测的动态占用图 $P_{\text{occ}}$：$$C_{\text{collision}} = \sum_{t \in \{1\text{s}, 2\text{s}, 3\text{s}\}} \max_{p \in \text{Footprint}(\tau_t^{(k)})} P_{\text{occ}}^{(t)}(p)$$动态车距 TTC 惩罚 $C_{\text{ttc}}$（权重 $w_{\text{ttc}} = 5.0$）：
计算本车道前向走廊内最近障碍物的碰撞时间 $\text{TTC}_t = \frac{\Delta x_t}{\max(v_t^{(k)} - v_{\text{lead}, t},\ 0.1)}$，对低于安全阈值 $2.5\text{s}$ 的轨迹施加惩罚：$$C_{\text{ttc}} = \max_{t} \text{ReLU}\big(2.5 - \text{TTC}_t\big)^2$$高速推进效率奖励 $R_{\text{progress}}$（权重 $w_{\text{prog}} = 1.0$）：
在无碰撞风险（$\text{TTC} > 3.0\text{s}$）时鼓励贴合目标巡航车速 $v_{\text{target}} \in [0, 33.33\text{ m/s}]$：$$R_{\text{progress}} = \frac{1}{T} \sum_{t=1}^T \left( 1.0 - \frac{\vert{}v_t^{(k)} - v_{\text{target}}\vert{}}{\max(v_{\text{target}}, 5.0)} \right)$$高速动力学可行性惩罚 $C_{\text{dynamics}}$（权重 $w_{\text{dyn}} = 2.0$）：$$C_{\text{dynamics}} = \max_t \text{ReLU}\big(|a_{y,t}^{(k)}| - 3.0\big)^2 + \max_t \text{ReLU}\big(\text{Jerk}_t^{(k)} - 8.0\big)^2$$5. CARLA 0–120 km/h 闭环双频控制器与动态安全守卫重构双频解耦执行：上层规划（5 Hz，每 0.2s）：运行 Qwen-Drive-1.0 + World Model + planner-rl 采样 $K=4$ 条轨迹，按上述奖励函数 $R(\tau^{(k)})$ 选出得分最高且 $C_{\text{collision}} < 0.2$ 的最优轨迹 $\tau^*$。底层跟踪（20 Hz，每 0.05s CARLA Synchronous Tick）：使用运动学前视插值控制器（横向 Stanley / 纯跟踪 + 纵向速度-加速度前馈 PID），根据实时自车位姿追踪 $\tau^*$，输出连续平滑的 throttle、brake、steer。废除旧版静态死锁守卫，升级为速度自适应动态 Guard：移除旧版 2.0 m/s 速度上限与 1.2 m 横向偏移死锁。新动态拦截条件：仅当出现 ① 预测车速 $v > 35.0\text{ m/s}$（126 km/h）或 $v < -0.05\text{ m/s}$；② 瞬时侧向加速度 $|a_y| = v^2|\kappa| > 4.5\text{ m/s}^2$；③ 净车头间距 < 2.0 m 或有效 $\text{TTC} < 1.2\text{s}$ 时，才触发分级缓刹或紧急制动介入。6. 立即执行步骤清单（Action Items）Step 1（状态核查与文档归档）：只读检查当前后台训练状态（若仍在运行切勿中断），将本架构规范完整保存至 docs/QWEN_DRIVE_HIGHWAY_120_ARCHITECTURE.md。Step 2（模型权重与接口核验）：编写独立验证脚本 scripts/verify_qwen_drive_components.py，验证本地 Qwen-Drive-1.0-4B、perception/、planner-rl/ 的权重加载、前 24 层截断、LoRA 挂载及运动学积分层的 FP32/BF16 精度与零后缀梯度泄漏。Step 3（高速数据集与采样器构建）：实现 Town04/Town06 80–120 km/h 专家数据采集配置及 SpeedBinBalancedSampler + 12 类元动作自动标注流水线。Step 4（两阶段后训练与闭环接入）：依次实现 Stage 1 SFT 训练器、Stage 2 World-Guided GRPO 训练器及 5Hz/20Hz 双频 CARLA 闭环评测脚本。
