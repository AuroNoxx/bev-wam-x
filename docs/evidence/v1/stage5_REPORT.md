# 阶段5：冻结模型感知退化压力测试

正式开环：3模型 × 10条件 × 9,600锚点；闭环：3模型 × 7条件 × 6种子 = 126 episodes。
闭环样本比阶段4的20种子小，CI可能较宽；不代表完整20种子复验。所有轨迹均为实际模型预测，没有重新训练。

## 主要结论与闭环成功率

| 模型 | 到达成功率（7条件，每条件相同6种子） | 碰撞/越界 |
|---|---|---|
| Joint | 42/42（100%） | 0 / 0 |
| Action-only | 26/42（61.9%） | 0 / 0 |
| ResNet | 42/42（100%） | 0 / 0 |

42次测试不是42个独立种子，而是6个种子在7种条件下重复。Action-only的16次未成功均达到时间上限，平均速度约0.16–0.21m/s。

- 当前闭环设定下Joint与ResNet成功率打平；尚未观测到Joint在闭环成功率上的优势。
- 开环遮挡条件下，Joint对ResNet的绝对ADE和相对clean的误差增量均更小。
- 连续丢帧时Joint绝对ADE更低，但相对其自身clean的误差增量略大；不能将其称为更小的退化幅度。
- 静态边界通道完全丢失时Joint开环更差：ADE 0.208421m，对比ResNet 0.193734m。
- 所有交付门禁通过表示协议执行完整、证据可核查，不表示已证明世界预测在所有退化下有效。

## 关键样本诊断

按照输入/标签选择参与者由无到有、参与者像素最大变化、首个恢复和首个噪声样本；见edge_cases/cases.json和图。
不按模型误差挑选案例。参与者出现可能只是进入视野；恢复标签来自原数据，本阶段闭环没有额外注入动作扰动。

## 如何解释这些结果

相同条件下模型绝对误差与相对clean增量都要看；某模型干净表现较差，不意味着退化增量小就更适合驾驶。
逐episode配对bootstrap原始结果在 open_loop/report.json 和 summary.json；CI跨零时不能声称显著优越。
固定空间掩码、周期性传输丢失、ego状态仍可用，均限制结论外推。闭环执行后各模型轨迹分叉，无法逐帧配对，只按相同seed配对episode。
Clean闭环与历史逐种子偏差单独存于 summary.json，不能把开环数值重现当成闭环一定完全相同。
