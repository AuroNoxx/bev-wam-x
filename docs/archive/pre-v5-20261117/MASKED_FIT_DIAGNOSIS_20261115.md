# Small train-only trajectory fit diagnosis

Same four train anchors, short four-frame masked input, non-EMA 967,710 parameters (width128, decoder2, heads4), seed1701, batch4, 512 steps, lr5e-4. No checkpoints or validation/test reads. Independent diagnostic scripts only; original baselines unchanged.

## Normalization and sample audit
Reconstructed all 25 future points directly from original poses and speeds. Largest cache difference below 3e-8 in normalized values. Position scales are x/50m and y/10m; speed/30m/s; heading sin/cos; 0.2s increments to 5s. Evaluation multiplies x/y by matching scales. No normalization mismatch found in these four windows. This comparison checks implementation consistency, not independent ground-truth accuracy.

Two hard-brake windows are near stopped (current signed speeds 0.420 and -0.045km/h; final displacements0.291 and0.077m). Two recording-start cut-ins are currently2.887 and4.781km/h but move40.60 and38.59m over next5s. The tiny set combines almost stationary and accelerating cases; not a highway-speed benchmark. Target kinematic residuals0.0053,0.0074,0.1087,0.1056m/s, not a large intrinsic kinematic contradiction.

Direct regression is deterministic (16/64 labels not applicable). It reaches0.272m at256steps,0.269m at384,0.478m at512. Thus these inputs/model can substantially fit the four target trajectories, but last-step quality is nonmonotonic and this is not a production replacement or generalization result.

PureFM final2.881m vs combined FM+physical auxiliaries+JEPA5.164m suggests loss/training balance merits investigation. Removing all auxiliaries at once cannot attribute the difference specifically to JEPA or kinematics; no such claim is warranted. Different objective modes are controlled diagnostics, not equal compute. Neither FM result passes an established overfit acceptance gate. 64 integration steps do not help on this seed, so merely increasing sampler steps is not the demonstrated fix. Dominant error is longitudinal: joint xMAE5.094m/y0.534m; pureFM2.842m/0.305m. Normalized isotropic noise has x/y physical scales50m/10m; coordinate scaling is internally consistent but optimization is not metrically isotropic.

Next justified work is an isolated physical-auxiliary vs JEPA ablation and a short FM learning-rate schedule/noise-scale diagnostic, with multiple evaluation seeds and fixed anchors before enlarging model or full training. Retain independent collision/progress/comfort assessment for later closed loop. No expert-path ADE alone establishes safety or optimal driving.

Source-level OCC causality remains uncertified. Local cached offline occ_label_gen uses a centered21-frame aggregator, whereas online occ_online_carla uses current plus cached past frames. Merely finding the offline file does not prove that downloaded v0.0.4 OCC was generated by it; verify official collection call path and release provenance separately. Even online simulator semantic LiDAR and bbox filling provide privileged information, not deployed perception guarantees.
