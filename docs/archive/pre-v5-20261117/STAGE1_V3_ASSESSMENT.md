# v3 是否可用：冻结模型补充诊断

2026-11-15。结论：训练及恢复流程通过，模型可以保留为研究基线；目前不足以验收为可执行规划器，更不能宣称支持 0–120 km/h。没有继续训练、改模型或读取最终测试集。

## 评估口径

固定第 60 轮 best，完整验证 1,124 个窗口、9 条路线，8 候选、16 个 Euler 采样步；采样种子 1908/2911/3911，每批加 batch index，BF16 和 channels-last 与训练一致。三个是采样种子，不是三次独立训练。窗口高度重叠，验证集用于选模，不是独立测试。

固定候选 0 在看真值之前指定，可排除 oracle 挑选，但不是实际风险选择器。此前训练日志 3.5994 m 是种子 1908 的全部 8 候选平均 ADE；本次相同种子复现为 3.599391 m。三种子全候选平均 ADE 3.5808 m，固定候选 0 的 ADE 3.5661 m，口径不同不能混用。

状态＋导航 ridge 直接复用已拟合模型输出，先逐数组验证 v3 的验证 state、trajectory 和窗口顺序与旧基线完全一致；帧修正没有改变它们。原基线用训练集标准化与预先固定 alpha=10。此对照不是同容量/同架构消融，不能直接断言 OCC 有害。

## 轨迹误差

| 方法 | 固定单条 ADE m | 固定单条 FDE m |
|---|---:|---:|
| 当前速度直线匀速外推 | 3.7781 | 8.6311 |
| 状态＋导航 ridge | 3.2551 | 7.2766 |
| v3 Flow 固定候选 0，三种子均值 | 3.5661 | 8.0269 |

v3 比匀速基线 ADE 改善约 5.6%，但比轻量状态＋导航基线差约 9.6%。因此学到了一些结构，但尚未证明 OCC Flow 在单条输出上带来足够收益。需要同架构、同初始化和同预算的无 OCC 对照才能判断 OCC 的净增益。

v3 minADE8 为 1.7215 m、minFDE8 为 3.3102 m，是按真值事后挑选的结果，实际驾驶不可直接获得；两个指标可能对应不同候选。候选中有更接近标注的轨迹，不意味着只做选择就能解决所有失败。

固定单条在 1/2/3/4/5 秒误差分别为 0.974 / 2.377 / 3.997 / 5.798 / 8.027 m。窗口-种子 ADE 的中位数、P90、P95 为 2.522 / 7.685 / 10.334 m，存在明显长尾。

前 1、2 秒的所有真值位置仍位于当前原 OCC 的 XY 矩形范围内，已有接近 1 m、2.38 m 的误差。3–5 秒按覆盖分组时，覆盖内组甚至更差，受速度、机动和预测时刻等混杂影响；既不能说扩范围必然解决，也不能说远距观测不需要。几何覆盖不等于真实可见空间。

## 减速与风险信号

按真值实际变化筛出“5 秒末速度较当前低超过 2 m/s”的 83 个窗口，来自 5 条路线；这是分析用的事后分组，不进入模型输入、不用于重新选 checkpoint。在这些窗口里，固定候选 0 的 5 秒纵向位置平均超前真值 12.749 m，末速度平均偏高 4.309 m/s；末纵向误差中位数 11.976 m，P10/P90 为 -5.324 / 31.972 m。这比仅按 HardBreakRoute 名称推断制动能力更直接，值得优先检查制动响应与过冲。

整个 HardBreakRoute 组的正负误差会相互抵消，末纵向有符号平均只有 -1.18 m，不能据此说急刹无问题。其末纵向误差 P10/P90 为 -16.32 / 16.88 m。

按日志未来 actor 的车身旋转包围盒检查，每 0.2 秒一次、包含车身尺寸和 bbox 局部中心偏移：

| 方法 | 有至少一次包围盒重叠的窗口比例 |
|---|---:|
| v3 固定候选 0 | 29.54%（三种子分别 333/320/343，各 1124 窗口） |
| 状态＋导航 ridge | 28.83%（324/1124） |
| 匀速外推 | 26.07%（293/1124） |
| 原日志专家轨迹，同一检查 | 0/1124 |

v3 的 HardBreakRoute 组为 57.38%（481 窗口、2 条路线），SequentialLaneChange 为 37.78%（135 窗口、1 条路线）。这些是高风险候选，不能当作 CARLA 闭环碰撞率：其他车按照日志专家行为响应，未针对候选重新仿真；离散检测可能漏掉帧间接触，且未覆盖所有静态障碍。基线自身也有高重叠率，其 ADE 较低不代表可部署。

## 平顺性与未完成项

固定单条的位置差分向量加速度平均 4.017 m/s²、jerk 平均 34.160 m/s³；同样差分的标注分别约 2.286 与 12.390。计算未平滑，包含位置噪声，因此不能当作乘员真实受力；但输出不够平顺的风险仍需控制器跟踪验证。第 60 轮运动一致性残差较此前降低，不代表碰撞、车道合规和执行约束均通过。

当前没有合法车道边界越界率、完整车体连续扫掠、控制器跟踪结果、可部署选择器成绩或 CARLA 闭环。缺失不是零风险。现有数据也没有 80–120 km/h 样本。

## 下一项优先工作

冻结 v3，不再以增加轮数作为主要改进手段。先只检查减速失败：按上述 83 窗口核对前车关系、专家/候选速度与位置时序、制动开始点、过冲和候选覆盖，选可复现片段测试执行与选择。确认主要失败机制后只改一个因素。随后用同架构状态＋导航消融检验 OCC 增益，不急于接世界模型掩盖轨迹问题。
