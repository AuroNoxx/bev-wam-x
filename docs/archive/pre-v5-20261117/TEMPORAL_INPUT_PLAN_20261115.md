## 可用状态、对象及掩码

抽样annotation存在自车 speed、acceleration、angular_velocity、位置/航向、ego world2ego、框尺寸；对象有 id、location/rotation、extent、speed、road/lane/section、world2vehicle 等（字段因对象类别可能不同），还有 teleport/disappear 标记。后续扩大历史前必须按每段遍历这些标记与位姿差分，重置记忆，不能跨片段/跨地图串联。

原始OCC为128×128×20的occ+seg；当前处理的255是unknown，0是源未填充，不是已验证free。历史坐标重投影产生的几何有效掩码、真实观测掩码和occupied掩码必须分开。不能用未来可见性给actor构造当前有效区域。原始对象框可用于仿真研究标签/诊断，但未经证明当前可观测的对象不能悄悄新增为部署actor输入。

源级未来融合依然未认证。延长历史不会消除源泄漏。必须保留oracle仿真OCC研究定位；准备来源调用链和时间戳证据后才谈部署输入认证。

## 建议第一版：近2秒高频，更早稀疏/压缩记忆

不是“把真实未来喂进去”。actor数据流为过去/当前OCC与状态导航 → 因果记忆 → 预测未来latent → Flow候选轨迹。未来真值仅作为训练标签，训练与推理的actor都只接收模型预测未来。

1. 第一消融保持原四帧作为基线，增加近2秒5Hz历史（−2.0至0，每0.2秒，共11帧）。只有需求经实验证明后再测近1秒10Hz，不能认为采样更密必然改善。
2. 更早 −3/−4/−5秒取稀疏帧，进入独立压缩记忆；例如每旧帧压缩到16个token而非保留160。近时段保留空间结构，由共享时序编码器聚合，避免把全部历史直接展开成巨大attention序列。这只是建议的token预算，不是已验证最佳结构。
3. 长短历史允许缺失：episode开头使用显式history-valid与age/时间间隔编码，禁止用未来/别段补齐；若用补齐张量，必须保持unknown和invalid区分。比较固定完整2秒子集与允许可变长度的全量训练，报告缺失比例和行为分组分布，不能通过筛样本悄悄改变评估难度。
4. 仅使用历史位姿变换对齐到当前ego坐标。运动物体仍保留多时刻位置与时间，不能按静态场景硬拼成一个“当前真值”。长历史不是长距离可见性，±25.6m源覆盖不会凭记忆变成实时远距感知。
5. 后续闭环使用流式记忆，明确生命周期、重置条件、更新频率及逐步等价性；测试一次性序列编码与逐帧增量编码是否在同样历史上输出一致。

## JEPA 多时域

先比较预测0.5/1/2秒latent；3/5秒作为低频、低分辨率或辅助标签候选，需按实际缓存原始索引重建。当前future缓存通常为1/2/3/4/5秒，0.5秒标签不能凭插值伪造。模型预测的不确定性和多模态必须与时距一起报告，不能把一个确定性latent叫可靠的所有未来。

用当前可获取几何范围定义监督边界，future observed/occupied仅用于loss masking，禁止进入actor。已有保守“当前已占据支持”丢失约29.2%未来车辆体素，需做独立标签覆盖消融；未观测/未填充不能当free负例。EMA目标止梯度，按同位置跨样本和跨时距验证方差/有效秩、时间敏感度、匹配与错配目标、动态区域，以及同支持范围持久化基线。增大模型前先证明这些目标含有可学动态。

## 可控验证顺序

A. 只读核验全部候选片段的位姿有限性、teleport/disappear、对象身份和索引缺口；报告按Town/route/行为分组的2/5秒可用率，不打开测试段。
B. 新缓存版本存历史索引、真实来源/名义时间区别、变换、mask、split哈希；原occ_v3只读，不覆盖。训练和开发验证仍Town12/Town13分离，不从验证尾部取训练记忆。
C. 用少量train窗口验证未来标签替换不变actor、历史因果、无跨episode记忆、坐标变换与流式等价，再做受控前反向/显存吞吐探针。
D. 相同训练预算对照0.6s、2s、2s+稀疏旧记忆；然后才比较未来时域配置。保留当前未通过的小样本拟合结论，不做长训。
E. 早期云端LLM教练在CARLA rollout阶段参与行为反馈和经验证候选，不用于提供不可观测未来真值。接口尚未接通，不宣称已经运行；供应商/授权/预算缺项仍需明确。
