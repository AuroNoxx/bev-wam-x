# CARLA 测试界面与 OCC 可视化

2026-11-14：已实现实时 OCC 网页，采用用户最终选择的 **左半屏网页 / 右半屏 CARLA**，不使用悬浮小窗。仅用于交互测试；训练设置独立。

## 启动与退出（Windows PowerShell）

在项目根目录运行：

```powershell
.\scripts\Start-OccViewer.ps1
# 可选：尝试 60 Hz；须先停止旧客户端，等退出后新参数才生效
.\scripts\Stop-OccViewer.ps1
.\scripts\Start-OccViewer.ps1 -SimHz 60
```

网页为 http://127.0.0.1:8765/，仅本机服务。启动器使用 `.venv-carla-ue5`，先启动/复用项目 CARLA，再启动 OCC 客户端并打开浏览器。`arrange_viewers.py` 将显示本项目网页的 Chrome/Edge/Firefox 窗口放左半屏、项目 CARLA 放右半屏。未识别到窗口时可用 Win+左/右方向键手动并排。不重复启动客户端；已运行时切换频率须先停止并等旧进程退出。

`Stop-OccViewer.ps1` 释放本客户端创建的车辆/传感器、恢复仿真设置，保留 CARLA 窗口。关网页不停止仿真。不要同时运行其他同步 tick 客户端。

## 镜头操作

- **右侧 CARLA**：默认跟车环视：按住左键拖动实时看四周，镜头持续跟车移动；松手后平滑回正到车后方（指数回正时间常数 0.16 秒，约 0.6 秒大部分回正）。F2 恢复跟车环视。F1 可额外脱离车辆飞行，但不是默认观察方式。用户要求暂缓本次实际拖拽验证。
- 快捷键仅在本项目 CARLA 获得前台焦点时有效，不影响其他应用。自由模式不再每帧写 spectator 位姿；车辆照常自动驾驶，镜头不参与模型输入。
- **左侧 OCC**：左键拖动旋转、右键拖动平移、滚轮缩放，支持跟随车辆、自由观察、俯视、重置；和 CARLA 镜头互相独立。

CARLA 原生观测镜头说明：https://carla-ue5.readthedocs.io/en/latest/start_first_steps/

## 当前显示内容与限制

- 当前为 CARLA Traffic Manager 自带驾驶演示，**没有加载训练后的策略或世界模型**。测试窗口已可用，不代表完整模型闭环已完成。
- 语义 LiDAR：48 线、110 m、180k 点/模拟秒、10 Hz 旋转；合并约 0.12 模拟秒的带采样位姿扫描，生成 0.6 m 占用体素。显示区域为车前 100 m、后 50 m、左右各 45 m、高度 -4 至 +10 m。
- 这些是 **命中表面占用**。未观测体积未知，空白不能解释为可通行；尚不等同于公开训练数据中的稠密 OCC。正式评测仍须完成坐标、类别、分辨率及可见性定义对齐。
- 显示道路/地面、车辆、植被、行人等语义颜色，自车实体与交通车白色包围盒。地图车道中心用点显示，不冒充预测轨迹。世界模型面板明确标注未加载。
- 队列长度有界，旧显示帧可被替换，显示不阻塞控制。扫描缓存有界；不会持续保存原始点云或训练数据。Three.js 0.180.0 已存于 viewer/vendor，附 MIT 许可证，不依赖在线 CDN。

## 频率与性能

- 默认仿真/控制目标 **30 Hz**，可设 60；网页绘制封顶 60 FPS，OCC 数据目标 5 Hz。三者为不同指标。
- 已观测未加载模型的 60 Hz 配置仅约 30–32 个 tick/墙钟秒；30 Hz 配置在并排 GUI 下约 28–30 Hz。初次加载、切窗等情况会降低瞬时值。目标频率不等于实测性能。
- 同步固定 dt 下若未达到目标，模拟时间会落后墙钟；正式实时评估须记录 real-time factor。不能通过改 dt 改变训练数据的时间定义。
- 训练后测试没有反传/优化器开销，但仍包括 CARLA、OCC 编码/规划/世界模型推理和网页绘制，不能预先断言显卡占用低。届时再测推理延迟和完整闭环吞吐。
- 当前网页提供实际 tick 速率、处理耗时、OCC 更新/绘制 FPS、体素数、车速和控制量；日志在 logs/occ-live。Town12 首次加载车辆所在地图块可能较慢，首 tick 等待上限 90 秒、后续 20 秒；超时记录失败并清理自建 actor，不能当作正常运行。
