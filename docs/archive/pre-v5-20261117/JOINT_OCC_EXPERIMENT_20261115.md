# OCC 未来表征与 Flow 联合实验：设计与核查

2026-11-15，本次用户明确要求恢复学习式联合模型研究。它是独立离线实验，不替换当前经典规划闭环，不改旧默认入口，不要求先通过原阶段一。本文件记录实施前选择；实测结果另见 JOINT_OCC_RESULTS_20261115.md。

## 已核实的现状

- `models_v1.py::FlowPlanner`：历史为 4×20×64×160 三维 OCC，时刻为 −0.6/−0.4/−0.2/0 秒。20维状态依次为 speed/30、ax/10、−ay/10、−gyro_z（原始已是 rad/s）、近远导航点 XY 各两维 /50、近远六类导航 one-hot。没有未来车况输入。
- 历史每体素两维 embedding，把时间与高度展平为160通道，加XY坐标后卷积；pool到8×20空间token，维度192，4层6头轨迹Transformer decoder。并非显式因果时序网络，但当前4帧均为过去/当前。
- 输出25×5，点间隔0.2s、总长5s，分别为 x/50、y/10、sin(yaw)、cos(yaw)、speed/30。当前自车 FLU：x前、y左、z上。默认absolute，8候选，16步Euler；采样后归一化航向并截非负speed。训练噪声插值含标签是FM监督定义，不能用于报告推理成绩。
- `stage1_objective.py`：FM MSE＋t≥0.5局部终点估计的XY SmoothL1、运动一致性、单位航向、负速度约束；权重1/.2/.1/.02/.02。辅助作用在局部估计，不是完整采样轨迹。
- `TrajectoryWorld`：同旧编码器，未来专家25×5轨迹＋当前state为条件，输出5×20×8×64×160类别logits，时距1–5s；weighted CE，255忽略，0是源未填充类，不是verified-free。原源码入口默认仍指occ_v1，正式v3必须显式settings，不能误用默认。发现world测速报告，未发现正式world checkpoint；2,655,154参数、历史100步测速约0.1383s/步，不作为新模型估算。
- 原Flow v3最新best/latest均epoch59/global_step39720，60轮；全1124开发验证窗口meanADE8=3.59939m、meanFDE8=8.05281m、minADE8=1.74210m；min只是oracle上界。原始日志、汇总和断点已检查并登记哈希。
- 旧诊断：训练停车180窗口仍约+3.213m末纵向偏差，训练减速781窗口约+5.072m；历史运动及车辆扰动响应弱，但非唯一根因证明。cv_residual十轮改善停车却没改善减速且风险代理恶化；保留absolute，不借本实验同时更换参数化。
- 训练使用本项目Python 3.13/torch 2.11.0+rocm7.14.0，Lightning、StatefulDataLoader、VerifiedCheckpointIO。ROCm在PyTorch中也通过`torch.cuda` API访问，这不表示假设NVIDIA CUDA硬件。

## 推荐架构及本次实际取舍

共享逐帧空间编码器保留20层高度作为通道，OCC embedding后XY先降到32×80，两个stride2卷积生成8×20×64空间token。四帧在各位置做共享门控因果递推；加当前state/nav与空间位置。没有RGB、Qwen或独立BEV感知分支。

初版融合GRU在当前Windows/ROCm实际报`miopenStatusUnknownError`，改为Linear/pointwise门控递推。未改全局驱动、环境或依赖。

- 原架构Flow从头训练：比较历史结构，不把旧60轮权重当预算匹配基线。
- 无OCC：仅state/nav条件，使用与小模型相同Flow decoder；不读history。
- 同规模temporal_flow：共享新主干但无未来辅助损失。这一额外对照隔离“换主干”与“加入未来预测”的效应。
- auxiliary：未来头并行预测1/2s latent，与Flow共享主干；Flow仅读历史h。
- fusion：相同辅助任务；Flow memory只增加由当前/历史预测的latent，训练和推理路径相同。没有teacher forcing未来latent。

目标编码器是在线空间编码器的EMA副本，momentum .99，stop-gradient；优化器更新后更新EMA。在线未来编码和预测latent在同位置跨样本加标准差下界正则，避免只依靠空间位置变化掩盖坍塌。记录跨样本std、中心化有效秩、配对/错配目标MSE、静态持久化MSE、mask-only变化。EMA/variance并不保证学习到动态，必须看诊断。

辅助标签故意保守：先限制到当前**已占据**支持体素，再取未来1/2s；255/源0不监督为free。7类轻量解码器回归8×20位置内的已占据类别比例，以conditional CE校验语义信息。这是占据语义探针，不是完整3D OCC重建或可靠free预测。代价是不能覆盖从当前未填充位置进入的新障碍，必须在结果中保留；后续可比较“固定当前几何覆盖内所有未来已观测occupied”标签方案，但不能把源0当空闲来造负例。未来unknown/mask只用于标签损失，不能传给actor；目标编码器仍可能利用未来覆盖变化，因此额外检查mask-only，不把当前防护称为完全消除所有捷径。

该轻量头为确定性2时距预测，不声称多模态场景模型。Flow仍生成多候选；旧轨迹条件world完全保留为后续独立反事实评估研究路径，未接回actor，亦未认证其预测未发生动作的后果。

## 最小实验与资源估计

配置在`configs/joint-occ-v1.json`，执行前冻结。每split选64窗口，24停车、24减速、16补充，尽量轮流取不同路线，文件清单和manifest hash留存。验证是行为富集探针，不代表完整分布。2初始化种子×5组，每组256次更新、batch8、同一AdamW/cosine/lr5e−4和原v3损失；aux另加latent/variance/semantic权重各.1。不按本次验证结果调参，不读测试。固定8候选/16Euler，并报告first、mean、median、min及分组，min不作主结论。

复用旧损失、轨迹尺度、数据契约、日志框风险、Lightning checkpoint插件/RNG恢复；新增审计、模型、独立Lightning任务/入口、因果恢复测试、汇总与配置。旧文件哈希前后核对，新增独立best/latest。best仅根据开发验证meanADE最小值选，min_delta=0；每32步和每轮末滚动latest，失败先保旧。数据内存化，StatefulDataLoader workers0，精确轮内恢复测试包含EMA。

先测10步热身之后的优化步耗时、训练总墙钟（包括验证/保存）、PyTorch allocated/reserved显存峰值、RSS、参数量和8batch推理延迟。估算全5296样本一轮优化下界=ceil(5296/8)×实测秒/步；另需实测全数据读取、1124验证和保存时间，不把内存64窗口吞吐当完整训练承诺。十组同更新数不等于同FLOPs，所以同时报告墙钟。

预登记推进门槛：对同规模temporal_flow，两种子均减速meanADE下降≥10%、整体退化≤5%、停车前冲不增加，且表征不坍塌探针通过。它仅决定是否值得下一轮，不能替代风险/闭环验收。长训、新采集、云LLM、RL均不自动执行。

闭环后续必须同场景/交通种子/车辆/控制器、同候选数和保护规则；逐组记录碰撞、非法越线、完成率/进度、舒适度、保护接管和原因、时延p50/p95/max，分别记录仿真秒、墙钟秒和暴露里程。当前实验没有把神经轨迹头接入经典控制链，随机或短训输出不直接用于闭环；无闭环数据时这些指标明确记未测。
