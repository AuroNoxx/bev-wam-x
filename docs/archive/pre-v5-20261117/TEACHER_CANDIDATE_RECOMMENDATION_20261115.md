# 教师候选实测与推荐（2026-11-15）

## 推荐结论

本机优先采用 **154.63M 非 EMA 参数教师**作为下一轮诊断候选：width 768、15 层轨迹 decoder、12 头、BF16、物理 batch 4；暂不正式长训。300M 级能运行，但当前没有证据证明它能解决拟合失败。下一轮建议最多 256 步诊断并检查确定性轨迹回归和 FM 采样的误差来源，不能把“跑得起”当成“学得好”。不要直接延长此探针；正式训练须独立配置并接入保存恢复。

## 数据与失败原因核查

只读既有选集的 64 个 train 窗口：状态和轨迹均有限，history OCC/pose 的 −1 偏移一致。当前“只在当前已占据体素上监督未来”的掩码保留 85.62% 未来占据体素，但仅保留 70.81% 未来车辆体素，约 29.19% 未来车辆体素没有受到这一路监督。这是明确覆盖限制，不是全部失败的唯一根因证明。不能直接把当前空值视作 free 补标签。审计文件 `artifacts/joint-occ-training-support-audit.json`；未读取保留测试集，源归档未来融合仍未认证。

150M级另做 4 个制动训练窗口、128 步、lr 1e-4、batch 4、梯度范数裁剪 1.0 的有界拟合诊断，固定相同采样 seed 比较训练样本。meanADE8 从 132.25m 降至 **47.10m**，minADE8 从 116.07m 降至 42.08m，latent MSE 2.000→1.610。虽然 loss/误差下降，绝对误差仍很差，**未证明小样本过拟合成功，更不能进入闭环独立驾驶**。不能与之前小模型不同数据/更新配置的 ADE 直接比较。

训练循环含前反向、裁剪、优化器、EMA、有限性检查与日志，128 步实测 17.846 秒，reserved 峰值 3.609 GiB。它不含模型构造、输入加载、冷启动前后采样评估与 checkpoint I/O。按此循环比例估计 256 步约 35.7 秒只是内存小样本优化段估计；**完整端到端训练耗时尚未测，不能承诺全量训练分钟数**。全量5296样本、batch4仅优化段粗投影约184.6秒/轮，实际还需采样验证、读取和保存；不据此自动开始全量或长训。

诊断脚本 `scripts/diagnose_joint_teacher_tinyfit.py`，结果 `artifacts/joint-occ-teacher-150m-tinyfit/report.json`。没有保存诊断权重；所有进程已完成。上述脚本不是可断点恢复的正式训练入口。
