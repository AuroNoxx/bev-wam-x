# 助手直接决策：两次多车交互测试

2026-11-15。两场均完成，每场7辆车、35秒模拟，共33次助手驾驶决策。自车自动驾驶关闭；助手依据返回的当前地图/车辆真值选择目标车道和速度，自建Pure Pursuit＋速度PI执行。四轮物理20Hz；助手每次推进1–3秒模拟，等待判断时暂停模拟时间。不是实时推理、盲测或专家资格验收。

## 预登记设置

`configs/agent_complex_scenarios.json` 保存两场背景车辆初始位置、目标速度和背景速度变化事件。背景车辆响应周围交通，但速度干预由场景脚本安排；自车没有预编排动作。场景设计者就是本次决策助手，结果不作为保留测试成绩。

Town12 road1157，自车从s150开始，限制s585以内的直线附近路段，避免把上轮未标定好的高速弯道误差混入交互判断。背景包括同车道前后车、左前/左后、右前/右后。每场新增场景事件与日志，未修改低层控制参数、模型或训练。

预登记数值初筛：零碰撞、零紧急保护介入、无驶出道路；自车速度>10km/h时，同车道前向闭合TTC≥2秒、前向时距≥1秒。完整驾驶任务还需单独查看实际动作，数值通过不等于专家通过。

## 第一场：前车减速＋左后快车＋右侧占道

运行 `logs/agent-drive/20261115-191306/`。

- 第14秒背景前车目标由50降至20 km/h，第24秒恢复到45。左后车目标80 km/h，右侧两车目标50；同车道后车也会响应自车。
- 第15秒助手观察到前车实际20.85、自车49.58 km/h，净距63.64米；左后车79.12 km/h、间距33.67米、闭合TTC4.10秒。选择保持中间车道并减速20，而非抢占左道。
- 第18秒左侧快车接近并排，助手继续持道减速。第21秒自车20.16 km/h，快车已通过并在左前32.48米，速度79.12；此时才选择左变道、渐增到50。
- 第27秒进入左道后有约0.44米过冲，助手保持车速观察；第30秒横向偏差收敛到0.034米。
- 在第35秒结束场景。原前车仍在相邻中间车道前方约13米，**不算完成超车或回切**；本场验证的是减速、等待快车通过、随后变道。

## 第二场：超车目标车道前后同时压缩

运行 `logs/agent-drive/20261115-191819/`。

- 中间车道前车目标35 km/h；左前车目标60，第11秒降到20，第26秒恢复55；左后车目标70。右侧两车目标40，同车道后车目标45。
- 第9秒助手看到左后车62.72 km/h、间距36.67米且仍在加速，先推迟变道，把目标降到35以匹配前车。
- 第12秒左前车已由59降到30.19 km/h，左后车69.32、间距19.17米、TTC2.80秒；助手明确取消本次超车意图，保持原车道。
- 随后原左后快车也因慢车减速，到第23秒仅23.01 km/h。助手持续持道，保持同车道前车约43米间距；右侧车辆同时从后方通过。
- 第35秒结束，自车约35 km/h，一直留在原车道。**这是变道开始前放弃超车，不是已经跨线后的变道中止或回退测试。**

## 复杂度和能力边界

这两场包含动态前车制动、后方快速接近、左右侧占道和间隙随时间收缩，属于比单纯巡航更复杂的交互开发测试。有效同车道TTC仍较宽裕、自车最高约50 km/h，不代表100–120 km/h紧急工况。

后续可以逐项增加：突然切入、连续切入、密集车流、匝道汇入、出口约束、目标车道被堵后的等待/重规划，以及已开始变道后的取消。但当前桥接器禁止中途直接反向换道，必须先实现并验收连续取消轨迹；不能声称这项已具备。

货车遮挡、传感器延迟和未知区域需要限制提供给助手的信息。当前使用全局真值，即使画面遮挡也不能当作遮挡推理通过。低附着需改变并核验物理摩擦，不能只改成雨天画面。任何实时延迟能力还要另测；当前暂停仿真只验证决策逻辑与执行结果。

两次单场景成功不形成统计可靠性，也不改变“尚未获得合格自采专家”的结论。本次不启动采集或训练。
