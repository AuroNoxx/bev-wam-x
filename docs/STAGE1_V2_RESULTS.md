# 阶段一 v2 续训结果

2026-11-15。训练与配对验证已经完成；阶段一尚未验收通过，不启动第二阶段。

## 执行与可恢复性

本轮从首版第 26 轮最佳权重初始化，使用新目标、新优化器与新步数。完整训练 15 轮 / 9930 步，每轮覆盖 5296 窗口；验证 1124 窗口。第 15 轮正常早停，退出码 0；最佳为本轮第 5 轮 / 3310 步。没有人为缩短样本或时距。

各轮训练与验证耗时合计 707.4 秒（约 11.8 分钟），稳定轮中位 45.33 秒。新目标测速 158.34 samples/s；100 个计时 step 峰值 allocated 0.517 GiB / reserved 0.715 GiB；正式运行日志最大 reserved 0.715 GiB，最少可用系统 RAM 15.70 GiB。这些是 PyTorch/系统内存指标，不是整卡总占用。

真实数据的 OCC 编码器、导航分支、输出层梯度均有限且非零，模型权重实际更新。轮内恢复参数最大差 0，优化器动量最大差 9.03e-10，优化器步数和调度器相同；模拟原子替换失败保留旧断点。证据在 `artifacts/lightning/stage1-v2-contract/`。

## 判断与下一步仍限阶段一

本轮整体平均 ADE 约改善 8.8%，速度一致性偏差约减少 53%，六类中五类平均 ADE 改善。但急刹车平均 ADE 退步约 5.2%，其 oracle ADE 退步约 21%，整体 oracle 终点误差退步约 9.2%。因此不把本轮权重标记为驾驶就绪，也不宣称架构问题全部修好。原版 best 完整保留，新 best 只是按预定平均 ADE 指标选出的实验结果。

后续阶段一工作优先检查急刹车两条验证路线的过冲/欠冲、制动开始时刻与候选覆盖，再用预先规定的分场景及终点约束设计下一次对照。当前证据不足以把急刹车退步归因于某一个辅助项；本轮同时改变了辅助目标和优化设置，若要归因需要控制变量实验。不要直接扩大模型、盲目增加轮数或接世界模型掩盖退步。
