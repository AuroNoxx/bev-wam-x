## Question and controls

Does a commanded two-second trajectory improve prediction of actual subsequent latent observations, compared with exactly the same history and no trajectory? Use original project code and native ROCm functional SDPA MATH. The immutable selected Stage 4 Joint encoder defines all latent targets. Freezing it prevents a moving or collapsed target representation from artificially improving the new prediction metric; Stage 4's trajectory policy is not retrained.

Extend the Stage 4 predictor with a 40→384→384 command embedding added before its Transformer blocks. Condition on ten commanded `(x,y,v,heading)` points at +0.2…+2s; positions/headings use the anchor ego frame. Fixed units scaling is (20m,5m,10m/s,1rad). Retain all four history observations, observed speeds/yaw rates and spatial tokens. Train predictor, history fusion and command embedding only. The unconditional model has identical modules, parameters, initialization and batches but substitutes zeros for command input. Also evaluate copy-current, candidate permutation, and the unadapted Stage 4 world predictor as explicitly horizon-mismatched context only.

Four output horizons are +0.5/+1/+1.5/+2s, deliberately extending Stage 4's +0.1…+0.4s to cover the full commanded action. Both new models use the same horizons and frozen target encoder. Do not compare errors across these different horizons as if they were the same task. Frozen targets remove the need to retrain VICReg; track actual target/prediction variance and content health rather than allowing a trainable target shortcut.

- Train: S/C/SC/CS, eight seeds each starting 410000 plus 10000 per map.
- Validation: CC/SS, four seeds each starting 510000 plus 10000 per map.
- Test: SCS/CSC, four seeds each starting 610000 plus 10000 per map.
- Anchors at prefix steps 20/50/80/110: 128/32/32 train/val/test contexts, four branches each (512/128/128 samples).

For each context repeat the exact saved prefix actions from reset. Compare all four ego history states and the complete vehicle-state snapshot (max abs tolerance 1e−5), plus every BEV byte before executing each candidate. The initial strict-byte run 001 stopped at train/S/410000/step80: one pixel at the image border changed from actor to road in one history frame, while positions/headings/speeds were float32-identical and only lateral velocity differed by 7.7e−8. The raw mismatch and failed run remain preserved. Before further training/testing, the numerical matching rule is revised to at most eight channel entries across the full four-frame history (8/262144); no image smoothing or target editing is applied. Every branch retains its raw observed history and scene states. The model uses one canonical reference history per matched context. Report the observed maximum; describe these as numerically matched physical prefixes, not guaranteed byte-identical renders. Any violation of either tolerance stops collection with raw MRE, without silent context deletion. This change is based only on simulator reproducibility evidence, not model/test performance.

Construct keep/left/right/slow trajectories using reference road geometry available to the experiment before branch execution. Lateral amplitude is sampled 1–2m by fixed seed, speed base is clipped observed speed 3–8m/s, slow factor 0.55. These are experiment commands, not a learned candidate generator or selector. Prefix state/history and command alone are inputs; realized future states, controls and encoded targets must never enter the predictor.

## Training and selection

Two prespecified training seeds 20261019 and 20261020; conditioned and unconditional run for each. Seed the same architecture initialization and batch order. AdamW, LR 1e−4, weight decay 1e−4, cosine schedule, 40 epochs, batch 64, bf16 training and FP32 evaluation, clip norm 5. All parameters including frozen parts remain within 15–30M. Use an actual ROCm forward/backward calibration before full runs; record hardware, memory, throughput and effective fixed config. Preserve failure batches, model/optimizer/random states and traceback on numerical failure or OOM; do not silently skip steps or alter the batch size.

Objective is masked latent MSE to the immutable target. Select each checkpoint by minimum full validation masked MSE only. Never select by test, counterfactual retrieval, case appearance or candidate sensitivity. Save best/last checkpoint, epoch metrics and random/optimizer/scheduler states. TensorBoard records losses, validation, gradients, timing and memory. At epoch 0 and every five epochs save actual prediction/target/mask NPZ, prediction-vs-target PNG and RRD from fixed validation contexts, through the public RerunLogger. No heatmap is called a decoded future scene.

## Evaluation and frozen thresholds

Evaluate all frozen selected checkpoints only after training completes. Save raw per-sample/per-horizon errors and outputs. Report:

1. Full masked latent MSE and per-horizon error; paired conditioned/unconditional errors with 2000 seed-cluster bootstrap resamples.
2. Same-context pairwise consequence-delta error: MSE between predicted branch differences and actual branch differences, only where both futures are valid. The unconditional branch difference should be exactly zero. Report actual target separation and predicted separation.
3. Candidate retrieval: for each prediction find closest actual branch target in the same context; report accuracy and tie handling (ties count as failure), plus empirical chance 1/4 and confusion counts. Mask all candidates at the same available horizons; report eligible counts.
4. Wrong-command control by a fixed within-context cyclic permutation, keeping history and target unchanged. Candidate sensitivity alone is not success; wrong-command error must actually worsen.
5. Actual command tracking ADE/FDE, collisions/off-road and sample masks, target/prediction variability, latency and resource use. These are branch experiments, not a new autonomous closed-loop driving success rate. ADE/FDE of a new trajectory prediction head remain missing because none is trained.

Scientific gates: both training seeds yield at least 5% lower latent MSE versus their matched unconditional run with the paired delta CI upper bound below zero; at least 5% lower consequence-delta error versus zero-difference baseline; retrieval ≥50% (chance 25%); wrong-command MSE strictly greater than correct-command MSE. Actual candidate target-delta energy must exceed ten times the same-command repeat noise floor. Data identity/alignment and parameter/resource/evidence gates must also pass. A failed scientific gate is a valid reported failure and blocks claiming reliable action consequences or proceeding to Stage 7; do not tune on test.
